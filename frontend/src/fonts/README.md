# Fonts

The same self-hosted faces as justin-chae.org (copied from its `public/assets/fonts/`), all OFL 1.1:

- `CommitMonoNF-*.woff2`: **CommitMono Nerd Font** (CommitMono by Eigil Nikolajsen, patched by the Nerd Fonts
  project), OFL 1.1 ([OFL-CommitMono.txt](OFL-CommitMono.txt), from [LICENSE-FONT](https://github.com/eigilnikolajsen/commit-mono/blob/main/LICENSE-FONT)). The site's subset: Basic
  Latin, Latin-1, General Punctuation, Arrows, Box Drawing, Geometric Shapes and Powerline. Other characters
  (Greek letters, math symbols) fall back to the system's monospace font.
- `DepartureMono-Regular.woff2`: **Departure Mono** by Helena Zhang,
  OFL 1.1 ([OFL-DepartureMono.txt](OFL-DepartureMono.txt), from [its LICENSE](https://github.com/rektdeckard/departure-mono/blob/main/public/assets/LICENSE)). One weight only, so
  display type is never bold.
